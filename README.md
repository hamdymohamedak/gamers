# Gamers

A React web app for browsing games by platform and store, with a clean modernized setup for quality and maintainability.

## Tech Stack

- React 18 + React Router 6
- MUI (Material UI)
- Create React App build tooling
- ESLint + Prettier for code quality

## Getting Started

### 1) Install dependencies

```bash
npm install
```

### 2) Start development server

```bash
npm start
```

### 3) Build for production

```bash
npm run build
```

## Quality Scripts

```bash
npm run lint
npm run lint:fix
npm run format
npm run format:check
npm test
```

## Project Structure

- `src/Component/` app pages and shared UI components
- `src/Component/Dashboard/` dashboard-specific views
- `src/img/` static assets
- `api/` backend/serverless-related files
